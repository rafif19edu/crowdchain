# CrowdChain UI mockups (Phase 3)

These files are the source of the **CrowdChain UI Design** canvas
(https://claude.ai/artifact/FKTmu4FhJpwMtLb6s4HLNr, private until shared from its Share menu).

- `canvas.json` lays out the 14 artboards on the canvas.
- Each `*.dc.html` file is one screen in the canvas's Design Component format. The files need the canvas runtime (`support.js`), so open them on the canvas rather than directly in a browser.
- They are design references only. They are **not** part of the application build: the real UI is built in React + shadcn/ui during Phase 5.
- All names, amounts and hashes in them are sample data.

See `docs/20-design-system.md` and `docs/21-screen-specs.md`.
